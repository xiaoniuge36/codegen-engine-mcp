# Browser Automation Skill 使用说明

## 这是什么

`browser-automation` 是一个 Cursor Agent Skill，用于指导 AI 正确使用浏览器自动化 MCP 工具进行前端测试和网页交互。

## 核心用途

| 场景 | 说明 |
|------|------|
| **前端页面测试** | 自动化测试登录、表单、列表等页面功能 |
| **UI交互验证** | 验证按钮点击、输入框填写、页面跳转是否正常 |
| **开发时实时验证** | 修改代码后，自动打开浏览器验证效果 |
| **回归测试** | 对已有功能进行自动化回归测试 |

## 对应的 MCP 服务器

```
cursor-ide-browser       → IDE 内置浏览器自动化
cursor-browser-extension → 浏览器扩展自动化
```

## 如何触发

### 自动触发

Cursor Agent 会根据 SKILL.md 中的 description 自动判断是否使用此 skill。

**会触发的用户请求示例**：

| 用户说 | 触发原因 |
|--------|----------|
| "帮我测试一下登录页面" | 包含"测试"+"页面" |
| "打开浏览器验证这个功能" | 包含"浏览器"+"验证" |
| "自动化测试表单提交" | 包含"自动化测试" |
| "怎么用浏览器MCP" | 包含"浏览器MCP" |
| "验证UI交互是否正常" | 包含"UI交互" |

### 手动触发

直接在对话中提及：

```
@browser-automation 帮我测试 localhost:3000

或者

使用浏览器自动化skill测试这个页面
```

## Skill 执行流程详解

```
┌──────────────────────────────────────────────────────────────┐
│  1. Cursor 启动时扫描 skill 目录                              │
│     - .cursor/skills/*/SKILL.md  (项目级)                    │
│     - ~/.cursor/skills/*/SKILL.md (用户级)                   │
└──────────────────────────────────────────────────────────────┘
                             ↓
┌──────────────────────────────────────────────────────────────┐
│  2. 读取每个 SKILL.md 的 frontmatter                          │
│     提取 name 和 description，注入到系统提示中                 │
└──────────────────────────────────────────────────────────────┘
                             ↓
┌──────────────────────────────────────────────────────────────┐
│  3. 用户发起请求                                              │
│     Agent 根据 description 判断是否匹配                       │
│     例如: "测试登录页面" → 匹配 "测试前端页面"                  │
└──────────────────────────────────────────────────────────────┘
                             ↓
┌──────────────────────────────────────────────────────────────┐
│  4. Agent 使用 Read 工具读取 SKILL.md 完整内容                 │
└──────────────────────────────────────────────────────────────┘
                             ↓
┌──────────────────────────────────────────────────────────────┐
│  5. 发现 SKILL.md 中的链接引用                                │
│     - [tools-reference.md](tools-reference.md)               │
│     - [examples.md](examples.md)                             │
│     Agent 根据任务需要决定是否读取这些文件                     │
└──────────────────────────────────────────────────────────────┘
                             ↓
┌──────────────────────────────────────────────────────────────┐
│  6. Agent 按照 skill 内容执行操作                             │
└──────────────────────────────────────────────────────────────┘
```

### 关键点：如何读取辅助文件

Agent **通过 SKILL.md 中的链接** 发现其他文件：

```markdown
## 更多资源

- 需要工具详细参数，请参考 [tools-reference.md](tools-reference.md)
- 需要完整使用示例，请参考 [examples.md](examples.md)
```

当 Agent 遇到复杂任务时，会：
1. 先读取 `SKILL.md` 获取基本指南
2. 如需详细参数 → 读取 `tools-reference.md`
3. 如需示例参考 → 读取 `examples.md`

### 标准操作流程

```
browser_navigate("http://localhost:3000")
         ↓
browser_lock()
         ↓
browser_snapshot()  ← 获取页面元素
         ↓
browser_fill(用户名)
browser_fill(密码)
browser_click(登录按钮)
         ↓
browser_snapshot()  ← 验证结果
         ↓
browser_unlock()
```

## 生效范围

| 存储位置 | 生效范围 |
|----------|----------|
| `.cursor/skills/` (项目目录) | 仅当前项目 |
| `~/.cursor/skills/` (用户目录) | 所有项目 |

当前 skill 存放在**项目目录**，仅在本项目中生效。

如需全局使用，将整个 `browser-automation` 文件夹移动到 `~/.cursor/skills/` 即可。

---

## 为什么需要这个 Skill

浏览器 MCP 工具有特定的**调用顺序约束**：

- 必须先 `navigate` 再 `lock`
- 交互前必须 `snapshot` 获取元素 refs
- 完成后必须 `unlock`

不按规则调用会导致失败。这个 skill 让 agent：

1. ✅ 知道有哪些工具可用
2. ✅ 知道正确的调用顺序
3. ✅ 知道每个工具的参数
4. ✅ 遇到问题知道怎么排查
